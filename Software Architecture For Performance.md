Different software architectures have different performance characteristics 
It is possible to design a software architecture for performance [(1)](https://youtu.be/Fs_T070H9C8?t=120).
It is difficult to effectively [[Optimization|Optimize]] a software when it has been built around an architecture that is not inducive to [[Hardware Utilization For Performance]].
It is difficult to transform a code based built around a software architecture that is detrimental to performance into one this is inducive to performance.
It is important to consider the needs of the application early in the development process and user or design data structures that support those needs well.
Very different architectures are appropriate if the program is computationally intensive or memory intensive.
